FAQ

Good questions.

Is Decklet really free?

Yes — the full app with all 120+ core widgets, four themes and four icon packs is free forever, with no ads and no account required. Pro adds encrypted sync, scripting and exclusive packs. Studio is for creators who publish to the Hub.

Do I have to install themes or icon packs?

Never. Themes and icon packs are entirely optional — the app looks great out of the box, and every pack is opt-in per deck. You can also build your own in Decklet Studio.

How does the Windows version differ from the Android version?

Each is a native app: WinUI 3 on Windows 10/11, native views on Android 8+. Decks sync between them, but each version respects its platform — taskbar flyouts and a quick-summon dock on Windows, home-screen and lock-screen widgets on Android.

What data does Decklet collect?

None. Widgets run locally; weather and RSS fetch straight from providers. Sync (Pro) is end-to-end encrypted. There is no telemetry and no ad SDK anywhere in either app.

Can I make my own widgets?

Yes — with a Pro plan you get widget scripting (JSON layout + JS hooks), and Studio adds the visual editor plus one-click publishing to the Hub with an 80% revenue share on paid packs.

Which platforms are supported?

Windows 10 (1809+) and Windows 11, x64 and ARM64. Android 8.0 through 15. A dockable web preview is on the roadmap.
